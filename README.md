# Offline Music Player

A modern Android offline music player.

## About

A music player designed for listening to local audio files.

## Technology

- Kotlin
- Jetpack Compose
- AndroidX Media3
- Room Database
- DataStore

## Features

- Local music library
- Background playback
- Playlists
- Favorites
- Search
- Equalizer
- Dark interface

In development.
